<sub>Updated October 15, 2026</sub>

Raff Guardian is priced per server, as the dashboard shows it on the Windows create page and on each server's Guardian tab.

## Price

| Item | Price |
|---|---|
| Raff Guardian on a Windows server | Free for 6 months, then \$10/mo |
| Uninstall | Any time, from the server's Guardian tab |

## Related costs

| Item | Billing | Notes |
|---|---|---|
| Snapshot before Windows updates | Like any snapshot: from your account's free backup and snapshot storage pool, then per GB above it | Raff Guardian deletes it once the server came back healthy. See [Virtual Machines pricing](/products/build/virtual-machines/details/pricing) |
| Your server while Raff Guardian shuts it down | The server is still billed while it is off | As with any shut down |
