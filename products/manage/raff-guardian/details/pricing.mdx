<sub>Updated November 21, 2026</sub>

Raff Guardian is priced per server, as the dashboard shows it on the Windows create page and on each server's Guardian tab.

## Price

| Item | Price |
|---|---|
| Raff Guardian on a Windows server | Free for 6 months, then \$10/mo |
| Uninstall | Any time, from the server's Guardian tab |

## Related costs

| Item | Billing | Notes |
|---|---|---|
| Snapshot before Windows updates | Like any snapshot: from your account's free backup and snapshot storage pool, then per GB above it | Raff Guardian deletes it once the server came back healthy. See [Virtual Machines pricing](/products/build/virtual-machines/details/pricing) |
| Your server while Raff Guardian shuts it down | The server is still billed while it is off | As with any shut down |
| Remote Desktop users (Licences tab) | \$8.00 a person a month. The first purchase and each raise are paid in the checkout for the days until the 1st, then renew on the 1st of every month; a lower or an end refunds nothing for the current month | Every Windows server with Raff Guardian, pay-as-you-go included: billed by the month, never by the hour. See [Remote Desktop users](/products/manage/raff-guardian/quickstart-guides/remote-desktop-users) |
| Microsoft Office LTSC Standard 2024 (Licences tab) | \$24.68 a person a month, for every Remote Desktop user of the server. Paid in the checkout for the days until the 1st, then renews on the 1st of every month; a lower or Remove refunds nothing for the current month | Pay-as-you-go included, by the month; needs Remote Desktop users. See [Microsoft Office and Visio](/products/manage/raff-guardian/quickstart-guides/microsoft-office) |
| Microsoft Office LTSC Professional Plus 2024 (Licences tab) | \$33.70 a person a month, for every Remote Desktop user of the server. Billed as Office Standard | Pay-as-you-go included, by the month; needs Remote Desktop users |
| Microsoft Visio LTSC Standard 2024 (Licences tab) | \$12.53 a person a month, up to the number of Remote Desktop users. Billed as Office | Pay-as-you-go included, by the month; needs Remote Desktop users |
| Microsoft Visio LTSC Professional 2024 (Licences tab) | \$27.65 a person a month, up to the number of Remote Desktop users. Billed as Office | Pay-as-you-go included, by the month; needs Remote Desktop users |
| SQL Server Express (Licences tab) | Free: Microsoft's free edition, installed by Raff Guardian with no licence and no charge | See [SQL Server](/products/manage/raff-guardian/quickstart-guides/sql-server) |
| SQL Server Standard (Licences tab) | \$261.34 per 2 cores a month, 4 cores at least (\$522.68 a month). Paid in the checkout for the days until the 1st, then renews on the 1st of every month; the cores follow a resize from the next charge; Remove refunds nothing for the current month | Pay-as-you-go included, by the month. See [SQL Server](/products/manage/raff-guardian/quickstart-guides/sql-server) |
| SQL Server Enterprise (Licences tab) | \$983.97 per 2 cores a month, 4 cores at least (\$1,967.94 a month). Billed as SQL Server Standard | Pay-as-you-go included, by the month |
| SQL Server Web (Licences tab) | \$16.34 per 2 cores a month, 4 cores at least (\$32.68 a month), SQL Server 2022. Billed as SQL Server Standard | Pay-as-you-go included, by the month |
