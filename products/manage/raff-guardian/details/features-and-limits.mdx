## Secure this server

**Secure this server** on the **Security** tab proposes, in one approval, each of these steps that is not in place yet. Each step is also its own row under **Hardening** in **Settings**, and each has its own **Undo** under **Show details**, which puts back the exact values the server had before.

| Step | What changes | Could it break something | Undo |
|---|---|---|---|
| Remote Desktop only from your address | Only the address your browser uses, and the browser console, reach Remote Desktop | Yes, if your address changes. Press **Keep it** within 10 minutes; if you do not, the earlier list comes back by itself | Yes |
| Network Level Authentication on | Remote Desktop checks the password before it shows the sign-in screen | Only very old Remote Desktop programs | No: Raff Guardian never turns it off. You can turn it off in Windows (System Properties, Remote) |
| SMB 1 off | The old Windows file sharing goes off, after the next restart | Devices older than 2007 | Yes |
| Windows Firewall on | Every network type blocks what no rule opens. Each app that listens at that moment gets its own rule first | An app that starts later needs its port opened under **Apps** | Yes |
| Name broadcasting off | LLMNR, and NetBIOS on the public network card, stop answering name lookups | Windows servers of one private network that find each other by name without DNS | Yes |
| Old encryption off | TLS 1.0, TLS 1.1 and SSL 3.0 go off for the programs that serve connections, after the next restart | Old SQL Server clients, accounting programs and payment terminals | Yes |

- The one approval leaves out **Old encryption off** (press it on its own if you want it) and, on a server with a private network, **Name broadcasting off**. Remote Desktop comes last.
- A value your company sets by Group Policy is never written: the step reads "set by your company policy".
- On a domain controller (Active Directory), name broadcasting off leaves NetBIOS on, Windows Firewall opens the directory ports to the private network only, and **Remote Desktop only from your address** also lets your private network in.
- If a step is changed back in Windows, Raff Guardian tells you under **Security** and never applies it again on its own.
- Uninstalling Raff Guardian leaves these settings as they are.

## What needs a mode other than Watch only

On **Watch only**, Raff Guardian changes nothing. These need **Raff manages everything** or **Ask me before changes**:

- Installing Windows updates, also with **Install now**.
- Blocking addresses, and **Block now**.
- Changing who can reach Remote Desktop.
- Applying a step of **Secure this server** (undoing one, and **Keep it**, work in every mode).
- Restarting a service, freeing disk space, updating Microsoft Defender's definitions, quick scans.
- **Restart** and **Shut down** through Raff Guardian (on Watch only they use the standard way).

These work in every mode: unblocking an address, adding a Windows user, switching one off or on, signing out, unlocking or setting a new password for a Windows user, questions about the server, and Raff Guardian's own updates.
