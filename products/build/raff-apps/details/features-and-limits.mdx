The facts about Raff Apps in one place.

## App types

| Type | Address | Scaling | Custom domains | Previews |
|---|---|---|---|---|
| Web | `https://<name>-<account id>.onraff.com` | Fixed, autoscaling, scale to zero | Yes | Yes, from GitHub |
| Private | `<name>.<namespace>.svc.cluster.local` | Fixed; autoscaling with scale to zero | No | No |
| Worker | None | Fixed | No | No |
| Cron | None | None. **Concurrency** decides if runs overlap | No | No |
| Job | None | None. One run per **Run now** | No | No |

See [App types](/products/build/raff-apps/concepts/app-types).

## Sources

| Source | What Raff does |
|---|---|
| GitHub | Builds the repository's Dockerfile, or detects the stack (Node.js, Python, Go, Ruby, PHP, Java and more) and builds it. Every push to the branch deploys. |
| Docker image | Pulls a public image and runs it. Nothing is built. |
| Template | Runs one of 16 ready apps. See [Raff Apps templates](/products/build/raff-apps/details/templates). |
| Docker Compose | Proposes one app per service in a pasted compose file. |

## Limits

| Item | Limit | Notes |
|---|---|---|
| Region | US East | |
| Instances per app | 6 | Fixed instances or the autoscaling maximum. Contact support to raise. |
| Instances per account | 20 | Web, private and worker apps. Paused, failed and not yet deployed apps count too. Contact support to raise. |
| App name in the address | 50 characters | A short suffix is added when the name is taken in your account |
| Default port | 8080 | Web apps get the port in `PORT` |
| Reserved ports | 8008, 8012, 8013, 8022, 9090, 9091 | Web apps and private apps that scale to zero |
| Build time | 15 minutes | |
| Repository size | 100 MB | GitHub |
| Time to turn ready | 5 minutes, or 10 minutes with a health check | Per deploy |
| Request duration | 5 minutes | Web apps |
| Sleep after | About 15 minutes without requests | Apps with scale to zero |
| Outbound TCP port 25 | Blocked | Use port 587 or 465, or an HTTP API |
| Environment variable names | 253 characters | Letters, digits and underscores, not starting with a digit |
| Database link prefix | 64 characters | |
| Custom domains | Web apps | Error after 24 hours without working DNS |
| DNS checks | Every 30 seconds | **Check now**: 5 times in 10 minutes |
| Previews | Per size, table above | Web apps from GitHub. A preview runs on Micro and is removed 7 days after its last push. Forks are skipped. |
| Free database | 1 per account | Pauses after 7 days without connections |
| Saved shell commands | 50 per app | |

|---|---|

| Every other template | Micro (0.25 vCPU · 512 MB) |

## Included with every app

- Automatic HTTPS for the onraff.com address and custom domains.
- Build logs, runtime logs, metrics (CPU, memory, instances, and requests for web apps), a shell inside running instances and an activity timeline.
- Deploy history with rollback to any deploy that went live.
- Encrypted environment variables.
- A spend cap, on by default at \$50 a month.
