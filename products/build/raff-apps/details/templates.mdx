A template is a ready app: Raff fills in its image, port, health check and the settings it needs to start. Every template is a web app with its own https address. Choose **Template** on the create page.

Sizes: Micro is 0.25 vCPU · 512 MB, Starter 0.5 vCPU · 1 GB, Standard 1 vCPU · 2 GB, Pro 2 vCPU · 4 GB. See [Raff Apps pricing](/products/build/raff-apps/details/pricing).

## Postgres

- **Required** (Umami, Wiki.js): the app does not start without a database. The create page offers Postgres only: the free plan when your account's free database is still open, else the \$7.99 plan.
- **Optional** (n8n, Metabase, Grafana, Vaultwarden, Vikunja): the create page also offers **No database**. Without one, the app keeps its data inside itself, and that data is lost when the app restarts or redeploys. Use Postgres for anything you want to keep.
- **No** (the rest): the app needs no database. Any data it keeps inside itself is lost when the app restarts or redeploys.

With Postgres, Raff links the database before the first deploy and fills in the template's own database settings, always with TLS. See [How apps connect to databases](/products/build/raff-apps/concepts/database-links).

## Sizes

The create page lists smaller sizes than a template's smallest, but turns them off and marks them **Too small for** the template. Metabase, LibreTranslate and Stirling-PDF run out of memory on smaller sizes. You can move to a bigger size at any time.

## Settings Raff fills in

These appear under **Environment variables** on the create page, and you can change them:

| Template | Setting | Why |
|---|---|---|
| Metabase | `JAVA_OPTS=-XX:MaxRAMPercentage=75` | Lets Java use most of the app's memory |
| LibreTranslate | `LT_LOAD_ONLY=en,es,fr` | Loads English, Spanish and French. All languages take several GB and too long to start. On Standard, keep to three languages. |
| Vikunja | `VIKUNJA_SERVICE_PUBLICURL` | Set to the app's address; Vikunja does not start without it |
