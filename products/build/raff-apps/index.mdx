<sub>Updated October 19, 2026</sub>

Raff Apps runs your code without servers to manage: websites and APIs with an https address, private services, background workers, scheduled tasks and one-off jobs. Deploy from a GitHub repository (every push deploys), a public Docker image, one of 16 ready templates such as n8n and Metabase, or a Docker Compose file. Link a Postgres database in one step, add your own domain, and start from 0.25 vCPU and 512 MB for $3 a month, in US East.
