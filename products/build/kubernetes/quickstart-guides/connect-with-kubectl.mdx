<sub>Updated August 24, 2026</sub>

Every cluster exposes its API server on a public endpoint (`https://<cluster-id>.k8s.raffusercloud.com:6443`). Access is by the cluster's kubeconfig.

There are two ways to get one, and the difference is only about renewal:

| | How you get it | When it stops working |
| --- | --- | --- |
| **CLI** (recommended) | `raff kubernetes kubeconfig <cluster-id>` | Never — it fetches a fresh token for every command and stores no credential on disk |
| **Dashboard download** | **kubeconfig** button on the cluster | After 7 days by default — pick 1 hour to 30 days under **Settings → Access**, or switch to the CLI |

Every credential we issue expires. Rotating access invalidates all of them at once.

## Before you start

- A cluster in **Running** state
- [kubectl](https://kubernetes.io/docs/tasks/tools/) installed locally

## Steps

### Option A — the CLI (nothing to renew)

```bash
raff kubernetes kubeconfig <cluster-id> --save ~/.kube/config
kubectl get nodes
```

The file it writes contains no credential: `kubectl` calls the Raff CLI for a
short-lived token before each request, the same way `gcloud` and `aws eks`
work. Anyone who copies the file cannot use it without your API key.

### Option B — download from the dashboard

<Steps>
  <Step title="Download the kubeconfig">
    Open the cluster and click **kubeconfig** in the header (also available under **Settings**).
    <Frame>
      ![Cluster Settings page with the kubeconfig Download button](/images/products/compute/kubernetes/kubeconfig-download.png)
    </Frame>
  </Step>
  <Step title="Point kubectl at it">
    ```bash
    export KUBECONFIG=~/Downloads/<cluster-name>.yaml
    kubectl get nodes
    ```
    You should see your control-plane and worker nodes in `Ready` state.
  </Step>
  <Step title="Deploy something">
    ```bash
    kubectl create deployment web --image=nginx --replicas=2
    kubectl get pods -o wide
    ```
  </Step>
</Steps>

<Warning>
A downloaded kubeconfig grants **full cluster-admin access until it expires** (7 days by default). Store it like a password and never commit it to a repository. For CI and anything long-running, use the CLI instead — it keeps no credential on disk. You can also issue one from the [API](/api-reference/kubernetes/get-kubeconfig), and **Settings → Access → Revoke** invalidates every issued kubeconfig immediately.
</Warning>
