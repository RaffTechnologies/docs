**The control plane is free.** You pay for worker nodes, storage nodes, and optionally the HA control-plane fee.

## Two billing modes

- **Pay-as-you-go** — every worker/storage node bills per hour at its plan's hourly rate while it exists. Clusters created through the [API](/api-reference/kubernetes/create-cluster) are always pay-as-you-go.
- **Subscription** — created through the dashboard checkout; the cluster's node set is a monthly commitment. Growing the cluster (scale-up, new pool, HA upgrade) goes through checkout for the pro-rated difference; shrinking credits the remainder back to your balance. Deleting the cluster converts the unused subscription value to account balance automatically.

## Autoscaling and billing

On subscription clusters the committed base never changes from autoscaling: nodes the autoscaler adds above the base are metered hourly as overage and drop off when it scales back down. On pay-as-you-go, autoscaling simply changes the hourly total.
