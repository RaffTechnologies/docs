The facts about the Raff MCP server in one place.

## Server

| Item | Value | Notes |
|---|---|---|
| URL | `https://mcp.rafftechnologies.com/mcp` | |
| Transport | Streamable HTTP | Stateless: no session to keep alive |
| Protocol | Model Context Protocol, current specification | Includes MCP Apps for the order card in Claude |
| Sign-in | OAuth 2.1 (PKCE, dynamic client registration, refresh tokens) or a Raff API key as `Authorization: Bearer` | See [Sign-in and access](/products/ai/mcp/concepts/sign-in-and-access) |
| URL options | `read_only=true`, `features=databases,docs` | See [Read-only mode and tool groups](/products/ai/mcp/concepts/read-only-and-tool-groups) |
| Price | Free | You pay only for the resources you create, at the normal price |

## Limits

| Item | Value | Notes |
|---|---|---|
| Request size | 1 MB | A larger request is refused with `413` |
| Statements per call | 1 | `run_query` and `run_sql` run one statement each |
| Statement time | 15 seconds | Longer statements are stopped |
| Rows returned | 100 by default, up to 1,000 | Set `max_rows`; the answer says when more rows existed or did not fit |
| Answer size | 70,000 characters | A longer answer is cut and says so: query rows from the end, log lines from the oldest |
| Log lines | 100 by default, up to 1,000 | Set `lines` on `get_database_logs` |
| Slow queries | 10 by default, up to 50 | Set `limit` on `get_slow_queries` |
| Wait for a new database | Up to 150 seconds | A slower one comes back as starting; the order card and `get_database` follow it until it runs |
| Wait for a new public address | Up to 1 minute after the database runs | The address is handed over once it accepts connections. One call never runs past 200 seconds |
| Free databases | 1 per account | |
| Rate limit | 50 requests a second per person, with short bursts above | Apps signed in with Raff are counted per person, not per network address, so people using the same app do not slow each other. With an API key, see [Rate limiting](/authentication#rate-limiting) |
| Sign-in request | Expires after 10 minutes | Connect again from the app |

## Supported apps

Tested by Raff: Claude (web and desktop), Claude Code. Documented setup: [ChatGPT](/products/ai/mcp/quickstart-guides/connect-chatgpt), [Cursor](/products/ai/mcp/quickstart-guides/connect-cursor), [VS Code and Gemini CLI](/products/ai/mcp/quickstart-guides/connect-other-clients). Any app that supports remote MCP servers over Streamable HTTP works.
